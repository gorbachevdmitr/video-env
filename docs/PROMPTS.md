# Промпты для Codex Web

Пишите как заказчик, а не как оператор CLI: агент сам выберет движок, прочитает нужный скилл и
прогонит проверки. Полезно сразу назвать длительность, формат и тон — это дешевле, чем
переделывать.

## 1. Launch-ролик про продукт или репозиторий

```
Сделай 15-секундный launch-ролик про этот репозиторий. 16:9, 1080p30, тёмный фон,
жёлтый акцент. Три сцены: название, три ключевых преимущества, финальный кадр
с адресом сайта. Титры по-русски. Музыку подбери из того, что есть в репозитории.
```

Ожидаемо: `videos/<slug>/`, движок HyperFrames, скилл `brag`, `check` + `snapshot` пройдены.

## 2. Объяснялка с цифрами

```
Ролик на 20 секунд: объясни, как работает наш пайплайн из трёх шагов.
Нужны титры, счётчик цифр и плавные переходы между шагами. Стиль — сдержанный,
как у финансового отчёта, без игрушечных анимаций.
```

Ожидаемо: HyperFrames, сцена на шаг + титры, проверка контраста в `check`.

## 3. Вертикальный клип под Reels/Shorts

```
Возьми out/interview.mp4, оставь лучшие 25 секунд, убери паузы, сделай 9:16
с кропом по лицу, добавь субтитры по речи и выгрузи под reels.
```

Ожидаемо: `ffmpeg-skill` (`silence.py`, `fit.py`, `caption.py`, `export.py --preset reels`).

## 4. Ролик из данных

```
Сгенерируй 5 вариантов одного ролика из data/rows.csv: по одному на строку,
подставь в титры название и цифру. Формат 1080x1350.
```

Ожидаемо: Remotion (`videos/<slug>/src/Root.tsx` с `<Composition>` на строку или пропсы),
manifest на каждый вариант.

## 4b. Когда нужен конкретный визуальный приём

```
Сделай ролик на 15 секунд: счётчик цифр на входе, лоуэр-сёрд с именем на 8-й секунде
и переход cross-dissolve между сценами. Палитра — тёмно-синий и белый.
```

Ожидаемо: Remotion + `node scripts/add-component.mjs` (`stat-counter`, `lower-third`,
`cross-dissolve`), затем переписанный контент и `tsc` + `still`.

## 5. Правка существующего ролика

```
В videos/launch/index.html третья сцена заканчивается слишком резко.
Сделай мягкий выход и проверь, что длительность не поехала.
```

Ожидаемо: правка `compositions/scene-3-*.html` + `check` + `snapshot`, длительность сверена
с `video.json`.

## 6. Контроль качества перед выдачей

```
Проверь out/final.mp4 как будто это приёмка: длительность, кадры, громкость,
соответствие площадке. Если что-то не так — скажи что именно и почини.
```

Ожидаемо: `probe.py`, `look.py`, `check.py --platform`, при необходимости `loudness.py`.

## Чего не надо писать

| Плохо | Почему |
| --- | --- |
| «Сделай красиво» | нет ни длительности, ни формата, ни критерия готовности |
| «Отрендери 4К, потом посмотрим» | 4К в headless Chrome на CPU — это часы и деньги пода |
| «Напиши композицию и сразу отрендери» | без `check` и просмотра кадров брак уедет в финал |
| «Сделай как в том видео с ютуба» | агент не имеет доступа к видео; дайте ссылку на кадры или опишите словами |
| «Поставь музыку из интернета» | композиция должна быть офлайн-детерминированной; музыка лежит в репозитории |
